关于应用

Perfect SwiftUI Demos 是一款 SwiftUI 动画交互示例应用，包含聊天气泡发送过渡和动态外观主题选择示例。应用也提供相关视频教程与 GitHub 源码链接。

常见问题

聊天演示会把消息发给别人吗？

不会。聊天气泡页面是本地交互演示，不是即时通讯服务。输入内容仅用于当前演示效果。

教程或源码链接打不开怎么办？

这些页面由 YouTube、GitHub 等第三方服务提供。请检查网络连接，或稍后在浏览器中重试。
